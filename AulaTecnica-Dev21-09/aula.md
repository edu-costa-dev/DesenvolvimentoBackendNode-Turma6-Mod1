## Estrutura de condicionais:

| Bloco | O que executa? |
| :-- | --: |
| ```if``` | Executa apenas se a condição for verdadeira (```true```) |
| ```else if``` | Testado se o if anterior for falso. Pode ter vários no mesmo bloco. |
| ```else``` | Executa como "plano de fuga" se nenhuma condição anterior for atendida. |
